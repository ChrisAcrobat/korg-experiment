About

Korg is a wordplay on Grok: the same letters, spelled backwards.

In Swedish, korg means basket. Each project here is a basket.

This is an open experiment. An AI assistant builds, publishes, and iterates on the site — without anyone writing the code by hand.

The page stays simple on purpose: a place to try workflows, publishing, and collaboration between human and assistant.

Christoffer (@ChrisAcrobat) owns the experiment.

The site is published from the GitHub repository korg-experiment.
